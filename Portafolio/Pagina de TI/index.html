¿Qué es la Ciberseguridad?

Es el conjunto de medidas, tecnologías y prácticas utilizadas para proteger:

  • Dispositivos: Computadoras, celulares, tablets, servidores, etc.
  • Redes: Conexiones de Internet y sistemas de comunicación.
  • Datos: Información personal, académica, financiera o empresarial.
  • Sistemas: Programas y servicios utilizados por personas y organizaciones.

Principales Tipos de Ciberataques

  • Phishing: Engaño mediante correos o páginas falsas para robar contraseñas y datos bancarios.
  • Malware: Software malicioso (virus, troyanos, spyware) creado para dañar o robar información.
  • Ransomware: Malware que bloquea o cifra archivos exigiendo un pago para recuperar el acceso.
  • Ataques a redes: Aprovechan vulnerabilidades para interrumpir sistemas o acceder a ellos.

Protección de Datos Personales

Información a proteger: Contraseñas, correos, teléfono, ubicación, finanzas, fotografías y cuentas.

Buenas prácticas:

  • Contraseñas fuertes: Diferentes para cada cuenta.
  • Autenticación de dos factores (2FA): Capa extra de seguridad.
  • Actualizaciones: Corrigen vulnerabilidades ante atacantes.
  • Copias de seguridad: Para recuperar información afectada.
